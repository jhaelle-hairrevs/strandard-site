Cabinet Grotesk (Headlines)

Cabinet Grotesk is a commercial font and is not included in this package.

To use it:
1) Export a WOFF2 file for your licensed Cabinet Grotesk font (variable preferred).
2) Place it in this folder named exactly:
   CabinetGrotesk-Variable.woff2
3) Deploy.

If you use a different filename, update the @font-face src in /styles.css.
